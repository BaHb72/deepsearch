# memory 模块实现说明

## 模块定位

`deepsearch.memory` 负责提供智能内存管理能力，重点围绕大规模行情数据与回测序列的缓存、分块与回收策略，减少 Python 对象常驻内存造成的压力。

## 主要文件

- `smart_memory.py`：核心实现，包含分段缓存、引用计数、内存池与溢出到磁盘的逻辑。

## 核心概念

- `SmartBuffer`：封装可扩展的缓冲区，支持逐块加载与写回。
- `MemorySegment`：表示一段连续的数据块，记录起止索引、引用数与脏标记。
- `EvictionPolicy`：控制淘汰策略（LRU、LFU、自定义函数）。

## 关键流程

1. 模块根据数据量动态分配段大小，缓存命中时直接返回内存视图。
2. 当内存压力过大时，通过 `Evictor` 将冷数据写入临时文件或压缩存储。
3. 与 `infrastructure.cache` 协作，实现内存/磁盘/网络多级缓存。
4. 清理流程会在组件关闭时归档脏数据、释放文件句柄。

## 扩展与集成

- 可通过配置自定义淘汰策略与段大小，满足不同策略的需求。
- 若需要持久化缓存，请结合 `persistence` 模块统一管理路径与权限。
- 调试期间可启用统计日志，观察命中率与回收时间。
