# utils 模块实现说明

## 模块定位

`deepsearch.utils` 收纳通用工具函数与领域算法，按功能划分子包，供各业务模块调用。设计原则是保持高内聚、低耦合，避免业务逻辑泄露到工具层。

## 子目录

- `finance/`：金融计算工具，如收益率、风险指标、回测性能分析。
- `network/`：网络请求、重试、代理设置等辅助函数。
- `patterns/`：常见设计模式/结构实现，例如单例、观察者、管道等。
- `system/`：操作系统相关工具（路径、进程、锁文件等）。
- `time/`：时间处理工具，统一时区、交易日历换算。

## 核心约定

- 每个子模块应包含 README 或注释说明用途与输入输出格式。
- 工具函数必须保持纯净，不直接依赖全局状态或复杂类实例。
- 跨模块复用前应在此实现，避免复制代码。

## 扩展建议

- 新增工具时，确保具备完善的单元测试并在模块层导出。
- 涉及高频计算的函数应考虑使用 `numpy`/`pandas` 并避免重复转换。
- 系统层工具在 Windows/WSL 场景下需测试路径与编码兼容性。
