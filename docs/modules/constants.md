# constants 模块实现说明

## 模块定位

`deepsearch.constants` 汇总系统级常量、业务枚举与默认值，避免魔法数字散落在代码中。模块按用途拆分文件，便于查找与维护。

## 文件概览

- `__init__.py`：聚合导出常量、枚举类型。
- `business.py`：业务语义相关常量，如订单状态、交易方向、账户类型。
- `defaults.py`：系统默认参数，包括线程数、缓存大小、重试次数等。
- `events.py`：事件类型与路由标签，供 `event` 模块引用。
- `system.py`：路径、环境变量键名、平台特定配置。

## 使用约定

- 所有跨模块共享的魔法值必须在此登记，并提供文档注释说明来源。
- 若常量与配置联动，应在 `config` 中读取后覆盖默认值，并在注释中说明优先级。
- 业务常量更新需评估对数据序列化/数据库的影响，必要时编写迁移脚本。
