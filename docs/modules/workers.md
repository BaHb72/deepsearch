# workers 模块实现说明

## 模块定位

`deepsearch.workers` 管理后台异步任务与代理进程，负责任务调度、状态同步与资源隔离。典型场景包括数据拉取、批量回测、通知推送等耗时操作。

## 主要文件

- `proxy_manager.py`：维护工作进程池，支持任务分发、健康检查、自动拉起。
- `models.py`：定义任务、队列、代理实例等数据模型。
- `__init__.py`：导出工厂方法与公共类型。

## 核心数据结构

- `WorkerTask`：描述任务 ID、参数、优先级、重试策略。
- `WorkerProxy`：封装子进程/线程信息、通信通道与资源占用。
- `WorkerStatus`：实时状态快照，用于监控与 CLI 查询。

## 关键流程

1. 任务通过 `messaging` 或直接调用 `proxy_manager.submit()` 进入队列。
2. 管理器选择空闲代理执行任务，并在执行前注入所需依赖。
3. 任务执行过程中的日志与指标通过 `observability` 上报。
4. 任务完成或失败后更新状态，并按策略决定是否重试。

## 扩展与集成

- 支持多执行模式（线程、进程、远程代理），扩展时需实现统一接口。
- 若任务需要访问外部资源，优先通过依赖注入获取，避免共享全局对象。
- 监控指标建议与 `monitoring` 模块联动，提供队列长度、执行耗时等观测值。
