# 炒股心得知识库

本文件聚焦可被 AI 快速吸收的交易洞察，重点记录触发条件、决策规则与数据信号，以便后续模型直接对接和学习。

## 使用方法
- 每条心得以结构化条目写入下方 YAML 清单，支持脚本解析或直接用于向量化。
- 若策略更新，直接修改对应 `id`，保持知识库与最新实战同步。
- 鼓励补充量化指标或可观测信号，便于后续自动化校验。

## 记录模板
```yaml
- id: insight_<主题关键词>
  context:
    trigger: <触发事件或背景>
    inference: <对市场影响的核心判断>
  strategy:
    decision_rules:
      - <执行规则 1>
      - <执行规则 2>
    execution_notes: <操作节奏、仓位指引>
  data_signals:
    - <需要跟踪的数据或指标>
  risk_controls:
    - <关键风控措施>
  expected_outcome: <目标收益或结构性机会描述>
```

---

```yaml
- id: insight_black_swan_followup
  context:
    trigger: "美股夜间出现黑天鹅事件，全球风险偏好急剧收缩"
    inference: "次日 A 股大概率低开并加剧板块分化"
  strategy:
    decision_rules:
      - "开盘阶段暂停追涨，等待指数是否出现恐慌性下探"
      - "资金回流时执行高低位切换，优先低位品种"
      - "聚焦处于上升通道且基本面稳健的个股，择机分批布局"
    execution_notes: "采用延迟买入策略，确认资金回流后再行动"
  data_signals:
    - "隔夜美股主要指数跌幅"
    - "A50 股指期货贴水幅度"
    - "北向资金开盘净流向"
    - "行业资金净流入排名"
  risk_controls:
    - "避免情绪化抄底，用实时数据验证节奏"
    - "对每个标的设定止损与加仓触发条件"
  expected_outcome: "在恐慌修复阶段捕捉结构性机会，维持低位核心仓位"

- id: insight_sector_sentiment_monitor
  context:
    trigger: "大盘持续下跌或恐慌扩散阶段"
    inference: "板块间将出现情绪分化，强势板块提供防御与反弹起点"
  strategy:
    decision_rules:
      - "实时跟踪各板块涨跌幅、换手率和资金流，筛选情绪保持正向的板块"
      - "优先观察强势板块内的龙头或低位即将放量标的，确认承接力后再介入"
      - "当领先板块开始走弱，及时降低仓位或切换到次强板块"
    execution_notes: "利用盘中分时数据建立板块强弱排名，按节奏分批建仓，保持灵活仓位"
  data_signals:
    - "板块实时涨跌幅与分时强弱指标"
    - "板块资金净流入、主力/超大单流向"
    - "板块涨停与跌停家数、连板高度"
    - "情绪指标：高位断板数、炸板率"
  risk_controls:
    - "设置板块整体回撤阈值，跌破时快速减仓"
    - "限制单一板块敞口，控制组合集中度"
  expected_outcome: "在整体弱势中捕捉相对强势板块，实现防守反击并保持组合活力"
```
