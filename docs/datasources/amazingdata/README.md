# AmazingData 文档索引

该目录用于沉淀 AmazingData 数据源相关资料，当前包含以下文档：

- `amazingdata_developer_manual.md`：**（主文档）** AmazingData Python SDK 接口开发文档，包含完整的API说明、数据字典和字段定义。
- `process_usage.md`：进程隔离版 Provider 使用指南（含 login_flow/alert_utils、订阅恢复、TypedDict 等）。
- `login_throttle.md`：登录节流策略与进程池协同。

> 历史沉淀或不再维护的材料可归档于 `docs/archive/datasources/amazingdata/`。
