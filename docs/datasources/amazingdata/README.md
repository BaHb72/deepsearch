# AmazingData 文档导航

本目录聚合 AmazingData 数据源相关文档，优先参考最新接口文档，再结合专题说明与分析报告。

## 推荐阅读

1. `amazingdata_developer_manual.md`
   - 最新接口文档转存版（Markdown 可检索），用于接口能力与参数查询。
2. `process_usage.md`
   - 进程隔离版使用说明与常见流程。
3. `login_throttle.md`
   - 登录限频与连接管理注意事项。
4. `query_kline_calendar_requirement.md`
   - `query_kline` 与交易日历相关约束。

## 目录说明

- `analysis/`: 接口梳理、差异分析与批次研究材料。
- `ad/`: 历史图像资料（开发手册页面切图）。
- 其余 `AMAZINGDATA_*.md` 与 `amazingdata_*.md`: 历史阶段产物与专题报告，按需查阅。

## 维护约定

- 新增或替换接口文档后，同步更新本文件与 `docs/overview/document_index.md` 的描述。
- 旧版接口文档如需保留，请放入明确归档路径并标注版本与日期，避免与当前文档混淆。
