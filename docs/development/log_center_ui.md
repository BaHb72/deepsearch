# 日志中心页面设计方案

## 设计目标
- 为运维与研发提供统一的实时/历史日志检索入口。
- 支持在单页内完成健康态势感知、问题定位、日志文件管理。
- 保证在 1920px 宽屏下信息密度最大化，同时兼顾 1366px 分辨率的可读性。

## 用户关键任务
1. 快速判断当前服务是否异常（错误量、波动情况）。
2. 通过组合条件检索定位目标日志，并查看上下文详情。
3. 对关键日志进行收藏/导出，或跳转到原始日志文件。
4. 追踪实时新增日志，延迟不超过 2s。

## 信息架构
- **顶部总览带（72px）**：左侧标题+运行状态 Tag+最近更新时间；右侧放置自动刷新开关、刷新按钮、下载原始日志、帮助入口。
- **健康指标区（第一行栅格 3×8）**：
  - 今日累计错误 / 警告数（TrendLine、同比箭头）。
  - 平均处理耗时（单位 ms，展示 P95/P99）。
  - 最近 5 分钟请求状态分布（堆叠迷你柱状）。
- **过滤器面板（折叠卡片，可收起）**：
  - 时间范围选择器（快捷：最近 5 分钟、30 分钟、4 小时、24 小时、自定义）。
  - 日志级别多选 Tag（ALL/TRACE/DEBUG/INFO/WARN/ERROR/FATAL）。
  - 来源服务下拉树（按业务域分类，可多选）。
  - 关键字搜索（支持 AND、OR、精确匹配）。
  - Request-ID / Trace-ID 输入框。
  - 组合过滤器保存为快捷方案（右侧下拉）。
- **主体区域（24 栅格，16:8 分栏）**：
  - 左侧（16 栅格）
    - `Tabs`：实时流、列表视图、时间线视图。
      - 实时流：SSE / WebSocket 推送，按级别着色，高亮关键字。
      - 列表视图：`Table`，字段包含时间、级别、服务、实例、摘要、耗时、状态码、TraceID。支持列筛选、排序、分页、无限滚动。
      - 时间线视图：`Timeline` + 折线趋势，展示选定时间段内每分钟错误/警告数。
    - 检索结果头部显示命中数量和查询耗时。
  - 右侧（8 栅格）
    - `Card`：选中日志详情（原文、上下文前后行、结构化字段）。
    - `Card`：智能洞察（自动聚合重复错误、建议的处理动作）。
    - `Card`：日志文件列表（最近更新 5 个，可展开进入完整列表）。

## 交互设计
- 自动刷新与实时流互斥；实时模式下顶部显示闪动指示灯，暂停后可继续。
- 列表行 hover 时显示操作：查看上下文、复制、标记为关注、跳转下载。
- 选中日志后右侧详情联动，同时支持固定在新标签。
- 关键字命中位置在摘要内高亮；支持双击展开为全文对话框。
- 空状态：按不同过滤条件提供提示与重置按钮。
- 键盘操作：`Cmd/Ctrl + K` 聚焦搜索框、`Cmd/Ctrl + S` 保存查询方案。

## 视觉规范
- 背景使用浅灰（#F5F7FA），主体卡片 8px 圆角，24px 内边距。
- 级别颜色：TRACE #909399、DEBUG #409EFF、INFO #36CFC9、WARN #FAAD14、ERROR #FF4D4F、FATAL #722ED1。
- 文字体系：中文字体优先 "HarmonyOS Sans"，行高 1.6；等宽内容使用 "JetBrains Mono"。
- 图表使用 @ant-design/charts 默认色板，搭配半透明渐变表示趋势。

## 技术实现要点
- 使用 React + Ant Design，结合 `ahooks` 的 `useRequest`、`useEventSource`（自定义）实现数据轮询与 SSE。
- 引入 Zustand 管理查询条件与收藏列表，保证跨 Tab 共享状态。
- 抽象通用 `useLogStream` Hook：负责连接 `/api/system/logs/stream`，支持暂停/恢复、错误重连。
- 接口：
  - `/api/system/logs/files` 获取日志文件列表，支持下载、查看。 
  - `/api/system/logs/stream` 获取实时/历史数据；历史查询通过 querystring 控制 `lines`、`follow`。
- 细粒度组件拆分：`LogFilterBar`、`LogMetrics`, `LogTable`, `LogStreamViewer`, `LogTimeline`, `LogDetailPanel`, `LogFileList`, `InsightPanel`。

## 响应式策略
- < 1440px 时，健康指标区改为 2×2（首行显示最关键两个指标）。
- < 1200px 时，主体改为 Tabs 全宽布局，详情面板通过 Drawer 呈现。
- 移动端仅保留查询、实时流与详情，默认关闭指标与文件列表。

## 验收标准
- 页面加载 3s 内完成首屏渲染并展示最近 100 条日志。
- 过滤器变更后 1s 内完成数据刷新，错误提示可定位原因。
- 实时流在后台运行时自动暂停数据渲染并提示恢复。
- 具备空状态、加载态、错误态的完整设计与实现。
