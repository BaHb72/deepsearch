# 交易日历为空导致 fallback 逻辑触发

## 基本信息

- **发现时间**: 2026-02-02
- **严重程度**: 中等
- **影响范围**: 实时行情模块
- **文件位置**: `c.a.m.trading_guard:180`

## 问题描述

系统启动时出现 WARNING:

```
交易日历为空，临时视 20260202 为交易日，允许实时行情继续运行
```

交易日历数据缺失，系统使用了 fallback 逻辑将当天视为交易日。

## 潜在风险

- 非交易日可能错误触发行情轮询，浪费资源
- 交易日历是行情调度的基础数据，缺失可能导致其他依赖模块行为异常

## 建议

- 排查交易日历数据来源（是否需要预加载/初始化）
- 确认 fallback 逻辑是否符合预期
