# 前端端口 3000 被占用

## 基本信息

- **发现时间**: 2026-02-02
- **严重程度**: 低
- **影响范围**: 前端开发服务器

## 问题描述

启动前端 `npm run dev` 时，端口 3000 被其他进程占用，Vite 自动切换到 3001。

```
Port 3000 is in use, trying another one...
VITE v7.1.10  ready in 194 ms
Local: http://127.0.0.1:3001/
```

## 潜在风险

- 前后端端口约定不一致（文档规定前端端口为 3000）
- 如果后端有 CORS 配置仅允许 3000，可能导致跨域问题

## 建议

- 排查占用 3000 端口的进程：`netstat -ano | findstr :3000`
- 如果是之前未关闭的实例，终止后重启
